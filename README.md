# Jardín Infantil - Sitio Web Profesional

Este proyecto es una landing page moderna y responsiva para un jardín infantil. Está pensada para presentarse a familias, mostrar actividades, publicar eventos y recoger inscripciones.

## Estructura del proyecto

- index.html
- css/styles.css
- js/script.js
- README.md
- assets/
- images/
- icons/

## Cómo ejecutar

1. Descarga o clona este proyecto.
2. Abre la carpeta en tu editor de código.
3. Inicia un servidor local (recomendado):
   - Si tienes Python:
     ```bash
     python -m http.server 8000
     ```
   - Luego abre en el navegador:
     ```text
     http://localhost:8000
     ```
4. También puedes abrir directamente el archivo `index.html` en el navegador, aunque un servidor local es la mejor opción.

## Cómo personalizar

Busca las marcas de comentario dentro del HTML para cambiar la información:

- Nombre del jardín
- Logo
- Teléfono
- WhatsApp
- Correo
- Dirección
- Redes sociales
- Fotos
- Actividades
- Eventos
- Blog
- Equipo

Las secciones con texto e imágenes de ejemplo están marcadas con información de ejemplo para reemplazar más adelante.

## Notas importantes

- La página es responsive para móvil, tablet y escritorio.
- Los enlaces del menú, CTA, WhatsApp y redes sociales están funcionando con rutas reales.
- El formulario es una versión funcional de ejemplo con validación local.
- No se requieren dependencias externas para que funcione.
- Puedes volverlo más avanzado en el futuro con backend para enviar formularios reales, pero por ahora está dentro del alcance solicitado.
